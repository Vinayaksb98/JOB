Improved matching: strict Supplier/Manufacturing Quality role gate; excludes software, developer, content, sales, marketing and support roles; evaluates job responsibilities, skills and experience. ATS weights: role relevance 25%, skills 45%, responsibilities 20%, experience 10%. Candidate baseline is editable in candidate_profile.py (14+ years). Run pip install -r requirements.txt then streamlit run app.py. This heuristic is not a commercial ATS score. Public feeds are not exhaustive; LinkedIn/Indeed are not scraped and missing work mode/date/location are not inferred.
